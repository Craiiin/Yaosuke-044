# 光线投射升级实验：Blinn-Phong 光照与硬阴影渲染
## 对比原版 Phong 光照的增强版 Taichi 渲染系统

---

## 一、实验概述
本实验是**上一版 Phong 着色实验的升级版本**，在原有光线投射、几何体求交、深度测试、UI 交互的基础上，完成两大核心改进：
1. **将 Phong 光照模型替换为 Blinn-Phong 光照模型**，使用半程向量 H 计算高光，提升渲染真实感；
2. **实现硬阴影（Hard Shadow）**，通过发射阴影射线判断交点是否处于阴影中，阴影区域仅保留环境光；
3. 强化代码鲁棒性：向量强制归一化、负值截断、颜色 clamp 防止过曝/黑噪点。

本实验完整对比了传统 Phong 与 Blinn-Phong 的视觉差异，并实现了基础光线追踪阴影效果。

## 三、与前一版实验的核心对比（最重要）

### 1. 光照模型升级：Phong → Blinn-Phong
**前版（Phong）**
- 使用反射向量 R 与视线向量 V 点乘计算高光
- 大角度入射时，高光边缘**锐利、生硬、容易断裂**
- 计算略慢，数值稳定性一般

**本版（Blinn-Phong）**
- 使用**半程向量 H = normalize(L + V)**
- 用 N·H 替代 R·V
- 大入射角时光照过渡**更柔和、更平滑、更接近真实物理材质**
- 高光区域更大、边缘更自然，无明显断裂

**视觉表现差异（报告必写）**
- Phong：在物体边缘、大角度观察时，高光会快速消失，边缘锐利；
- Blinn-Phong：高光衰减更平滑，边缘过渡柔和，在大入射角下依然能保留自然高光，更符合真实材质观感。

---

### 2. 新增功能：硬阴影（Hard Shadow）
**前版：无阴影**
- 物体之间无遮挡阴影，场景缺乏立体感与层次。

**本版：实现阴影射线**
- 从物体交点向光源发射阴影射线
- 若射线中途击中其他物体 → **处于阴影中，只计算环境光**
- 若射线直达光源 → **正常计算漫反射+高光**
- 球体与圆锥之间产生**明显、边界清晰的硬阴影**，真实感大幅提升

---

### 3. 代码结构优化
- 新增 `intersect_scene()` 统一求交函数，阴影射线与主光线复用逻辑
- 阴影原点轻微偏移，**解决自遮挡黑纹问题**
- 所有光照向量强制归一化，杜绝黑块、乱码
- 漫反射/高光使用 ti.max(0.0, ...) 截断负值
- 最终颜色强制 clamp(0,1)，防止过曝发白

## 六、核心技术知识点
1. **Blinn-Phong 高光公式**
   - 半程向量 H = normalize(L + V)
   - Specular = Ks * (N·H)^shininess

2. **硬阴影实现逻辑**
   - 从交点 p 沿 L 方向发射阴影射线
   - 若交点与光源之间存在物体 → in_shadow = True
   - 阴影中只渲染 Ambient，更暗、更真实

3. **鲁棒性修复**
   - 所有方向向量必须 normalized()
   - N·L / N·H 必须 ti.max(0.0, ...)
   - 最终颜色必须 clamp(0.0, 1.0)
